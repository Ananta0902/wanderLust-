# 🌍 WanderLust – AI-Enhanced Travel & Property Listing Platform

> A full-stack Airbnb-inspired web application that enables users to discover, create, and manage travel accommodations with secure authentication, interactive maps, cloud image storage, and an AI-powered travel assistant.

🔗 **Live Demo:** https://wanderlust-4ahg.onrender.com/listings

---

## ✨ Features

- 🔐 Secure User Authentication (Sign Up, Login & Logout)
- 🏡 Create, Edit & Delete Property Listings
- 📸 Upload and manage listing images with Cloudinary
- ⭐ Post and manage property reviews & ratings
- 🗺️ Interactive location maps powered by Mapbox
- 👤 Authorization ensuring only listing owners can edit/delete their properties
- 💬 Flash messages for user-friendly feedback
- 📱 Responsive interface for desktop and mobile devices
- 🤖 AI-powered Travel Assistant for smarter trip planning and recommendations

